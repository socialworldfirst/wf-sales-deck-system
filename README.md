# WF Sales Deck System

The 2026 WorldFirst Sales Deck, extracted into a reusable visual system. Drop in any
content, it comes out in this format.

Live spec deck: https://socialworldfirst.github.io/wf-sales-deck-system/ (password `wf`)

Build a deck with the **`/sales_deck`** skill.

## What's here

| Path | What |
|---|---|
| `index.html` | Gated build of the spec deck (generated by `build_gate.py`) |
| `system_spec.html` | Ungated source: the system documented as a deck in its own format |
| `kit/sales_deck.css` | Component library: slide shell, splits, glass cards, stat bands, lockup, light mode |
| `kit/sales_deck.js` | Deck runtime: progress dots, counter, keyboard nav, currency-matrix canvas, `?only=<id>` single-slide mode |
| `fonts/` | Poppins Light / Regular / Medium / SemiBold |
| `assets/logos/` | WF wordmarks, Ant lockups, ant mascot, Alipay+, Bettr, 1688 |
| `assets/people/` | Avatar circles, buyer/seller photos, tinted scene circles |
| `assets/customers/` | Founder cutouts + customer logo chips for testimonials |
| `assets/product/` | World Card, app phone, dashboards, Live Rates / FX / transactions UI, currency cards, hub globe |
| `assets/props/` | 3D bell, padlock, coins, pie chart, landmarks, sports cutouts |
| `assets/bg/` | Flow-field overlay, dotted dome, dotted world map, concrete and gradient plates, photography |
| `assets/fx/` | Glow curves, orbs, arcs, connector terminals |

Not in the repo: the 167MB master `.pptx` (over GitHub's file limit) and the 28
`reference_slides/` PNGs. Both stay local in this folder.

## Design DNA

- **Type** Poppins only, weight 500 for headlines and stats, nothing heavier than 600.
- **Colour** deep purples `#13002D`–`#32006E` are the room. Pink `#FF0051` is a scalpel:
  one key word, one stat, one CTA, never more than about 15% of a slide. Lavender
  `#DDC0FF` is the secondary voice. Ink `#1F2323` and cream `#F1F1EB` on light.
- **Two-tone** headlines (white line, pink payoff) and labels (bright key words, lavender
  connectives) are the most recognisable patterns in the deck.
- **Light mode** is part of the system: cream, concrete texture, photography in
  pink-to-violet gradient frames. Set `data-mode="light"` on the section.

## Rules that keep it looking real

1. Never `box-shadow` an image. Extracted PNGs carry transparent padding, so the shadow
   draws a rectangle around the element box instead of the artwork. Use
   `filter: drop-shadow(...)`, which follows the alpha.
2. Full-bleed photos need a purple multiply veil, otherwise they read stock-blue and fall
   out of the palette.
3. `flowfield_overlay.png` is healed. The original had rectangular holes erased behind the
   cover headline and logo which showed as plates under any other layout;
   `flowfield_overlay_ORIGINAL.png` keeps the raw file.
4. Screenshot every slide before shipping, one at a time, via `?only=<slideId>` at
   1920x1080. Full-page captures lie.
5. Real numbers only, one idea per slide, lockup on every slide but the cover.

## Rebuilding the gated page

```bash
python3 build_gate.py
```

Reads `system_spec.html`, encrypts the slide markup with AES-GCM (PBKDF2, 100k
iterations) and writes `index.html`. Password `wf`.
